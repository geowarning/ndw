# 自然灾害预警（网页版）

由微信小程序「自然灾害预警」完整移植的单页网页应用，**纯前端、无需后端、无需构建**，浏览器直接打开即可运行，手机/电脑浏览器均可使用。

视觉为「全息指挥中心」主题：全屏 **3D 点阵全息地球**（经纬网 + 扫描扇形 + 灾害城市脉冲标注）与 **中国全息态势图**（发光国界/省界、扫描线、城市可点击直接切换），配合半透明青色光效卡片；顶部固定导航、目录位于右上角（移动端折叠为汉堡菜单）。

## 如何打开

- 最简单：双击 `index.html`，用任意现代浏览器（Chrome / Edge / Safari / 微信内置浏览器）打开。
- 手机使用：把整个文件夹放到任意静态网站空间（或手机本地 HTTP 服务），手机浏览器访问 `index.html`。
- 不需要安装 Node、不需要编译，也没有任何第三方 CDN 依赖。

> 必须保留文件夹结构（`index.html`、`css/`、`js/` 相对位置不变），整体复制/上传。

## 区县口径（重要边界）

- 华风接口为**城市级**数据（无区县级 Key）：天气与预警请求仍按城市发起，区县层面做**本地匹配与过滤**。
- 官方正文明确提到区县时（如“重点关注龙湾区、瓯海区”），对应区县显示状态点并可过滤；官方未细分到区的笼统预警按**覆盖全市**处理（区县弹层有说明）。
- 区县名为地名专名，非中文界面中保留中文拼写（如 Longwan 区写作“龙湾区”），其余界面文字一律翻译为所选语言。

## 数据来源

- 默认数据源：**华风爱科天气 OpenAPI**（中国气象局官方授权），接口地址 `https://openapi.weathercn.com`
  - 预警：`/alerts/v1/{locationKey}.json`
  - 实况天气：`/currentconditions/v1/{locationKey}.json`
  - 城市解析：`/locations/v1/cities/translate`（已预填常用城市 Key，查询这些城市不消耗定位请求）
- 备选数据源：高德开放平台天气接口（需在 `js/config.js` 填入自己的 Key；预警字段不保证）
- 行政区划边界与区县坐标：阿里云 DataV 地理数据开放平台（`geo.datav.aliyun.com`，仅构建时获取并已固化为本地数据，运行时不再请求）。
- 网页版在浏览器中**直接请求官方接口**（接口已开放跨域访问 CORS），不经过任何中间服务器，因此不受小程序「request 合法域名」限制。
- 接口请求统一使用中文原文，非中文界面的全部文案由本地多语言模块翻译；中文界面显示官方原文。
- 防御指南、次生灾害概率、应急电话/物资/避险要点为本地静态知识数据。次生灾害概率为基于预警类型与级别的经验估算（概率 = 区间下限 + (上限−下限) × 级别权重，红 1.0 / 橙 0.75 / 黄 0.5 / 蓝 0.25），**不是官方概率预报**，仅供避险参考。

## 配额与缓存

- 当前内置的是华风标准测试 Key：每日 500 次免费调用、5 QPS。
- 已内置两级本地缓存以节省配额：预警 15 分钟、实况天气 30 分钟（可在 `js/config.js` 的 `cacheMinutes` / `cacheWeatherMinutes` 调整）；城市选择面板的状态点同样走缓存。
- 已加载的预警会登记在内存中，即使缓存过期，从已打开页面进入详情也不会失败。
- 多人/高频使用请在华风平台升级为正式付费 Key，替换 `js/config.js` 中 `weathercn.apiKey` 即可，无需改其他代码。
- 设置页可手动清除缓存、查看累计请求数。

## 文件结构

```
natural-disaster-warning-web/
├── index.html          唯一入口（含全息地球 canvas）
├── css/
│   └── styles.css      全部样式（全息指挥中心主题、响应式布局）
└── js/
    ├── shim.js         浏览器适配层：wx.request→fetch、wx.storage→localStorage、请求计数
    ├── config.js       数据源与缓存配置（API Key 在这里）
    ├── data.js         级别配色、12 类防御指南
    ├── cities.js       全国省份/城市与预填城市 Key
    ├── districts.js    800+ 区县坐标、城市坐标（DataV，含港澳台手工补全）
    ├── china-geo.js    国界/省界 GeoJSON（简化抽点）
    ├── i18n.js         5 语言词条、地名/天气/风险/防御/测验/急救翻译
    ├── risk.js         次生灾害概率推算
    ├── api.js          华风/高德数据获取、区县提取、缓存、城市状态、内存注册表
    ├── holo-globe.js   3D 点阵全息地球
    ├── china-holo.js   中国全息态势图（SVG，城市可点击）
    ├── charts.js       环形图 / 柱状图 / 折线图（canvas）
    └── app.js          hash 路由、顶部导航与各视图的渲染/交互
```

## 部署提示

- 这是纯静态文件，放到任意静态托管（内网 Web 服务器、对象存储静态网站、GitHub Pages 等）即可访问。
- 浏览器要求：支持 ES5 以上语法、fetch、localStorage（近年所有主流浏览器均支持）。
- 城市通过手动选择，覆盖全国；定位权限未强制使用。
